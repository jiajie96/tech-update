# AI Agents Weekly Update — July 3, 2026

## Highlights

- **MCP goes stateless — final spec lands July 28**: The Model Context Protocol's 2026-07-28 release candidate is out, with the headline change being a stateless protocol layer: requests like `tools/call` become fully self-contained, carrying protocol version, client info, and capabilities with each request. This makes MCP far easier to run and scale in serverless agentic systems.
- **Oracle ships Fusion Agentic Applications**: Oracle announced four agentic supply-chain applications plus an AI Agent Studio for building reusable agents inside Fusion Cloud SCM — one of the clearest examples yet of agents embedded directly into core enterprise systems of record.
- **Coding-agent market consolidates around three players**: Claude Code (~$2.5B annualized revenue), Cursor (~$2B ARR), and GitHub Copilot dominate, while Zhipu AI's new ZCode entered the fray and pushed Zhipu's market cap past $128 billion.

## Detailed Updates

### MCP release candidate previews a stateless future
The Agentic AI Foundation published the MCP 2026-07-28 release candidate, with the final spec due July 28. Making the protocol stateless at the transport layer means agent infrastructure can route, retry, and load-balance tool calls without sticky sessions — a significant maturity step for the protocol since Anthropic donated it to the AAIF. ([AAIF blog](https://aaif.io/blog/mcp-is-growing-up/), [Anthropic](https://www.anthropic.com/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation))

### Oracle embeds agents in the supply chain
Oracle's four new Fusion Agentic Applications — Inventory Planning Command Center, Supplier Qualification Workspace, Production Readiness Workspace, and Kanban Administrative Workspace — let procurement and manufacturing teams automate recurring decisions inside existing enterprise controls, with an Agent Studio for building and connecting custom agents. ([AI Agent Store](https://aiagentstore.ai/ai-agent-news/this-week))

### Coding agents: pricing shakeups and new entrants
June brought structural pricing changes across the big three: GitHub Copilot moved all plans to usage-based billing with AI Credits on June 1 and made Microsoft's MAI-Code-1-Flash model generally available; Cursor split Teams usage into first-party and third-party model pools and added a $120/seat Premium tier for all-day agent users; and GitHub added Claude Sonnet 5 to Copilot. Z.ai's ZCode launched to challenge all three. ([Developers Digest](https://www.developersdigest.tech/blog/ai-coding-tools-pricing-june-2026), [VentureBeat](https://venturebeat.com/technology/z-ai-launches-zcode-to-challenge-cursor-claude-code-and-github-copilot-in-ai-coding))

### Identity infrastructure for agents
Ory launched Agent DX, plugging its identity stack into coding agents like Claude Code, OpenAI Codex, and Gemini CLI via free plugins — developers can build and test authentication/authorization workflows without leaving their agentic dev environment. Agent-native auth is emerging as its own product category. ([AI Agent Store](https://aiagentstore.ai/ai-agent-news/this-week))

### Telecom gets agentic OSS
Symphonica introduced an agentic operational support system letting telecom providers design services through no-code and "vibe coding" chat interfaces, then orchestrate deterministic workflows over non-deterministic agents with governance and full traceability — a template for regulated industries adopting agents. ([Agentic.ai](https://agentic.ai/news))

### Framework landscape matures
Frameworks drawing the most attention now handle state, memory, tool usage, evals, and deployment rather than just wrapping an LLM: Google's Agent Development Kit (code-first, with local dev UI), Mastra (TypeScript-first with MCP and RAG support), and Strands Agents (model-driven tool reasoning). Toolkits like OpenSage point toward agents that autonomously configure their own sub-agents and tools. ([KDnuggets](https://www.kdnuggets.com/10-agentic-ai-frameworks-you-should-know-in-2026))
