# AI Agents Weekly Update — July 4, 2026

## Highlights

- **MCP's biggest spec revision lands July 28**: The MCP 2026-07-28 release candidate is out — the largest protocol revision since launch, making MCP stateless at the protocol layer and aligning authorization with OAuth 2.1 and OpenID Connect for enterprise deployments.
- **Claude Sonnet 5 raises the agentic bar**: Anthropic's June 30 release is billed as its most agentic model yet, autonomously driving browsers and terminals at near-Opus performance for far less cost.
- **Agent economics get real**: Salesforce reported $800M in Agentforce ARR (up 169% YoY), while GitHub Copilot's June switch to usage-based billing continues shaking up coding-agent pricing.

## Detailed Updates

### MCP 2026-07-28: stateless protocol, enterprise auth, MCP Apps
The final MCP specification is expected July 28, with the release candidate already available. The headline change is a stateless protocol layer: every request carries protocol version, client info, parameters, and encoded state, so any server instance can handle any request — eliminating sticky-session pain behind load balancers. The spec also aligns authorization with OAuth 2.1/OIDC, and MCP Apps (successor to MCP-UI) become a core way agents render interactive interfaces inside host environments. (WorkOS, AAIF)

### Claude Sonnet 5 ships as an agent-first model
Anthropic launched Claude Sonnet 5 on June 30, emphasizing autonomous tool use — browsers, terminals, long-horizon tasks — at a significantly lower price than Opus 4.8. The release intensifies competition in production agent deployments, where cost per task is becoming the deciding metric. (llm-stats.com)

### Coding agent market reshuffles
GitHub Copilot completed its move to usage-based billing with GitHub AI Credits, with paid-plan signups reopening after a June pause. Windsurf has been fully rebranded as Devin Desktop following the Cognition acquisition (Free/$20 Pro/$200 Max tiers). Claude Code, Copilot, and Cursor remain the three dominant tools. (Developers Digest, cosmicjs.com)

### Enterprise agents hit revenue scale
Salesforce reported $800 million in Agentforce ARR by Q4 fiscal 2026, up 169% year-over-year — one of the clearest signals yet that enterprise agent platforms are producing durable revenue rather than pilot spend. (Instaclustr)

### New agent products launch in the July 1 wave
Profound launched Profound Aim (July 2), an always-on background agent for marketing teams that converts AI-search signals into prioritized work. SnapLogic made MCP Builder generally available (July 1), turning existing integration pipelines into governed MCP tools. Visualping opened the public beta of its MCP server (July 1), and security startup Dawnguard launched its architecture-automation platform the same day. (Agentic.ai, openpr.com)

### Agent security shifts from theory to structure
Researchers marked July 2026 as a turning point for agentic AI security, with focus moving from theoretical vulnerabilities to structural, systemic defenses as autonomous agents embed deeper into enterprise workflows. (Adversa AI)
