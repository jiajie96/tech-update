# AI Agents Weekly Update — July 6, 2026

## Highlights

- **MCP goes stateless — final spec lands July 28**: A release candidate of the next Model Context Protocol revision is out, with the final specification expected July 28. The biggest change makes MCP stateless at the protocol layer, simplifying deployment in agentic systems at scale.
- **MCP enterprise adoption hits critical mass**: As of July 2026, 78% of enterprise AI teams have MCP-backed agents in production, 28% of Fortune 500 companies run MCP servers, and monthly SDK downloads sit around 97 million.
- **"Agent Zero Trust" becomes the security theme**: New frameworks from Google DeepMind and Anthropic push treating autonomous agents as potential insider threats, with cryptographically verifiable guardrails, scoped identities, and runtime monitoring.

## Detailed Updates

### MCP 2026-07-28 release candidate: stateless at the core
The Model Context Protocol's next revision reached release-candidate status, with final spec expected July 28, 2026. The headline technical change is making MCP stateless at the protocol layer, which makes servers easier to run, reason about, and scale in agentic systems. The Agentic AI Foundation frames the release as MCP "growing up" from a fast-moving experiment into infrastructure. (aaif.io)

### Enterprise adoption keeps climbing
A July 2026 state-of-play analysis reports 78% of enterprise AI teams now have MCP-backed agents in production and 28% of the Fortune 500 run MCP servers, with ~97M monthly SDK downloads. New enterprise tooling followed: SnapLogic made its MCP Builder generally available July 1, turning existing integration pipelines and APIs into governed MCP tools via templates. (andrew.ooo, agentic.ai)

### Agent security moves from theory to structure
July 2026 marks a turning point for agentic AI security, with the field shifting from theoretical vulnerabilities to systemic defenses. The dominant theme is "Agent Zero Trust" — high-profile frameworks from Google DeepMind and Anthropic argue agents must be treated as potential insider threats requiring verifiable guardrails, strictly scoped identities, and runtime monitoring. Underscoring the urgency, Trend Micro found 492 MCP servers exposed to the internet with zero authentication. (adversa.ai, cyberdesserts.com)

### New commercial background agents
Profound launched Profound Aim on July 2, an always-on background agent for marketing teams that turns AI-search signals (prompt trends, citations, sentiment, competitive benchmarks) into prioritized work. Dawnguard publicly launched its security-architecture automation platform July 1 with fresh funding, and XBTFX shipped an MCP Server and Skills Hub connecting coding assistants and automation frameworks to live trading accounts. (agentic.ai)

### Claude Science brings agents to the lab
Anthropic's newly launched Claude Science workbench includes MCP connectors such as Helix's GenoSphere, which gives approved researchers agent-mediated access to more than 500,000 linked clinico-genomic records — an early template for agent-driven scientific workflows in regulated domains. (agentic.ai)

### Framework landscape consolidates
Mid-year roundups from JetBrains and KDnuggets converge on a stable core of production frameworks: LangGraph, CrewAI, OpenAI Agents SDK, Google's Agent Development Kit (ADK), and Mastra, with ADK gaining ground as a code-first toolkit covering tools, sessions, memory, evals, and multi-agent patterns. LangChain, meanwhile, is promoting "agentic engineering" — swarms of agents redefining software workflows. (kdnuggets.com, blog.jetbrains.com, langchain.com)
