# AI Agents Weekly Update — June 12, 2026

## Highlights

- **Codex goes GA on Amazon Bedrock, passes 5M weekly users**: OpenAI's coding agent reached general availability on AWS (June 1) and gained Sites, in-thread Annotations, and six business plugins — extending the platform well beyond developers.
- **Anthropic formalizes $100M Claude Partner Hub**: A new Services Track targets system integrators and consulting firms implementing Claude agents in production, signaling the consolidation of an agent services economy.
- **Enterprise agent platforms arrive in force**: Snowflake, Alteryx, and Microsoft all shipped major agent infrastructure this week, framing agents as the new enterprise software layer.

## Detailed Updates

### Codex expansion: AWS GA, Sites, and business plugins
OpenAI announced "Codex for every role, tool, and workflow" (June 3), its biggest platform expansion since enterprise launch. Codex reached GA on Amazon Bedrock per OpenAI's June 1 announcement, now serves more than 5 million weekly users, and gained Sites, in-thread Annotations, and six business plugins aimed at non-coding business users. (Sources: OpenAI Codex changelog, dentro.de/ai)

### Anthropic launches Claude Partner Hub and Services Track
Anthropic formalized its $100 million partner program for enterprises deploying Claude in production, structured for system integrators, consultancies, and AI-native service firms. Anthropic also announced that Claude Agent SDK usage will draw from a separate monthly Agent SDK credit starting June 15. (Sources: buildfastwithai.com, morphllm.com)

### Snowflake Summit: CoCo becomes a full autonomous dev platform
At Snowflake Summit 26 (June 1–4, 20,000+ attendees), Snowflake unveiled 26+ capabilities turning its AI Data Cloud into a control plane for enterprise AI. Snowflake CoCo was elevated to a full autonomous development platform with a desktop app, SDK, Cloud Agents, and integrations with Vercel, Retool, and Superblocks. (Source: LinkedIn All Data and AI Weekly #245)

### Alteryx Agent Studio and MCP Server
At Inspire 2026, Alteryx unveiled Agent Studio plus an MCP Server, letting business analysts convert existing data workflows and business logic directly into autonomous agents without central IT involvement — another example of MCP becoming default enterprise plumbing. (Source: aiagentstore.ai)

### MCP and protocol consolidation continue
MCP has crossed 200 server implementations and ~97 million monthly SDK downloads, adopted by every major provider. The protocol layer is consolidating under the Linux Foundation's Agentic AI Foundation (AAIF), which anchors MCP, goose, and AGENTS.md, while A2A absorbed IBM's ACP for agent-to-agent communication. (Sources: Linux Foundation, WorkOS, ruh.ai)

### Coding agent market: pricing shake-up
GitHub Copilot switched to usage-based billing with AI Credits on June 1 (1 credit = $0.01, consumed per token). Devin 2.0 dropped entry pricing to $20, and Cognition's Windsurf acquisition yielded Devin Desktop. Grok Build entered the agentic coding fight on price. Claude Code, Cursor, Codex, and Antigravity have largely converged on one agentic coding blueprint. (Sources: Developers Digest, The New Stack)

### agnt8x: a marketplace for operating agents
EightX Labs opened agnt8x (June 8), a public platform for recruiting, onboarding, operating, and monetizing AI agents, publishing an Agent Manifest (EAM) v0.1 spec — an early attempt at standardizing agent commerce. (Source: aiagentstore.ai)
