# AI Agents Weekly Update — July 5, 2026

## Highlights

- **Anthropic launches Claude Sonnet 5, a cheaper way to run agents**: Released June 30, Sonnet 5 is billed as the most agentic Sonnet yet — planning, using browsers and terminals, and running autonomously at a level that recently required flagship-class models, at $2/$10 per million tokens through August. It matters because it sharply lowers the cost floor for production agent workloads.
- **X ships an official MCP server**: On June 30, X joined GitHub, Slack, Notion, Stripe, and Salesforce in offering a Model Context Protocol endpoint, letting agents read and act on the platform through a standard interface. MCP is increasingly the default way commercial platforms expose themselves to agents.
- **China publishes seven national standards for AI agent interconnection**: Announced this week, the standards cover agent architecture, identity codes and management, description, discovery, interaction, and tool calling — the first state-level attempt to standardize how agents find and talk to each other.

## Detailed Updates

### Claude Sonnet 5 targets the agent economics problem
Anthropic released Claude Sonnet 5 on June 30 and made it the default for Free and Pro users the next day. The company says it approaches Opus 4.8 performance on many agentic tasks — reasoning, tool use, coding — while costing a fraction as much, with introductory pricing of $2 per million input tokens and $10 per million output tokens through August 31. TechCrunch frames it as a deliberate play to make long-running agents economically viable, and reviewers note it completes multi-step tasks Sonnet 4.6 could not and self-checks its output unprompted. ([TechCrunch](https://techcrunch.com/2026/06/30/anthropic-launches-claude-sonnet-5-as-a-cheaper-way-to-run-agents/), [Anthropic](https://www.anthropic.com/news/claude-sonnet-5))

### X opens its platform to agents via MCP
X launched an official MCP server on June 30, making its platform directly consumable by AI tools and agents. TechCrunch notes this continues a broader trend of major platforms shipping first-party MCP endpoints rather than leaving integration to scrapers and third-party wrappers. For agent builders, official servers mean more reliable tool use and clearer terms of access. ([TechCrunch](https://techcrunch.com/2026/06/30/x-now-offers-an-mcp-server-to-make-its-platform-easier-for-ai-tools-to-use/))

### China standardizes agent-to-agent interoperability
China released seven national standards on AI agent interconnection, covering general architecture, identity codes, identity management, agent description, agent discovery, agent interaction, and agent tool calling. It is the most comprehensive government-led interoperability framework for agents to date, and it signals that agent identity and discovery are becoming infrastructure-level policy concerns, not just protocol debates among labs. ([gov.cn](https://english.www.gov.cn/policies/policywatch/202607/03/content_WS6a4727f8c6d00ca5f9a0c014.html))

### Coding-agent pricing keeps shifting under developers' feet
Two notable billing changes landed around the turn of the month. Claude Code's Agent SDK billing change went live, adding $0.08 per session-hour of active runtime on top of model token costs for API usage. Cursor, meanwhile, rolled out new Teams pricing that splits usage into first-party (Composer/Auto) and third-party API pools, plus a $120/seat Premium tier for developers running agents all day. Together they show vendors converging on usage-based pricing for always-on agent workloads. ([Developers Digest](https://www.developersdigest.tech/blog/ai-coding-tools-pricing-june-2026))

### Gemini 3.5 Pro slips to July over agentic token consumption
Google's Gemini 3.5 Pro is now expected in July 2026, with Google citing enterprise tester feedback about excessive token consumption during extended agentic tasks. The delay underscores that efficiency on long-horizon agent runs — not raw benchmark scores — is becoming the gating factor for enterprise model releases. ([Agentic.ai](https://agentic.ai/news))

### Jamf brings AI governance to Mac fleets
Jamf announced general availability of AI Governance on July 1, letting IT teams discover which AI tools and agents are in use across managed Macs, enforce policy controls, and produce audit-ready reports. As agents proliferate on employee machines, governance tooling like this is the enterprise counterweight. ([BuildFastWithAI](https://www.buildfastwithai.com/blogs/ai-news-today-july-1-2026))

### Profound launches an always-on marketing agent
Profound announced Profound Aim on July 2, a background agent for marketing teams that converts AI-search signals — prompt trends, citations, sentiment, competitive benchmarks — into prioritized work items. It is a good example of the week's broader pattern: agents moving from chat demos into persistent, workflow-replacing products. ([AI Agent Store](https://aiagentstore.ai/ai-agent-news/this-week))
