# AI Agents Weekly Update — July 9, 2026

## Highlights

- **MCP goes stateless — final spec lands July 28**: The biggest Model Context Protocol update yet ships as a release candidate, making MCP stateless at the protocol layer so requests like tools/call are fully self-contained. This removes sticky-session requirements that made large-scale agent deployments painful.
- **Microsoft launches $2.5B Frontier Company**: A new consulting organization with 6,000 industry experts to help enterprises plan and deploy AI agents, announced July 6 — a signal that the bottleneck has shifted from models to deployment.
- **Agent security is now a mainstream concern**: The NSA released official MCP hardening guidelines this month after critical auto-execution vulnerabilities were found in tools including Amazon Q, and 88.4% of organizations report at least one agent-related security incident in the past year.

## Detailed Updates

### MCP 2026-07-28 spec: stateless protocol, new agent authentication
The final MCP specification is expected July 28, with the release candidate already available. The headline change is statelessness at the protocol layer: version, client info, and capabilities travel with each request, eliminating operational headaches for horizontally scaled deployments. The update also overhauls agent authentication, which WorkOS calls the biggest change to how agents authenticate to tools since the protocol launched. MCP has now crossed 200 server implementations. (workos.com, aaif.io)

### NSA publishes MCP hardening guidelines amid vulnerability wave
July highlighted severe risks in agent architectures: critical auto-execution vulnerabilities were discovered in tools like Amazon Q, and researchers warn MCP is becoming a primary vector for agent hijacking. The NSA responded with official MCP hardening guidelines. AvePoint's 2026 State of AI report found 46.9% of employees use agents weekly or daily, while 88.4% of organizations experienced at least one agent-related security incident in the past year, with rising unsanctioned agent use. (adversa.ai, hpcwire.com)

### Microsoft Frontier Company: $2.5B enterprise AI deployment push
Microsoft launched Microsoft Frontier Company on July 6, a consulting organization staffed with 6,000 industry experts and backed by $2.5B to help enterprises deploy AI. The move reflects the market's shift from demos to workflow replacement — winners map one messy process, add human review, and prove time saved. (hpcwire.com)

### Salesforce opens CRM to coding agents; BNB Chain ships Agent Studio
Salesforce's Headless 360 now allows agents like Claude Code and Cursor to directly interact with CRM data. BNB Chain introduced Agent Studio on its mainnet, letting developers deploy autonomous agents in about 15 minutes, alongside an "Agent Survival Pack" enabling agents to pay autonomously with crypto. SnapLogic made its MCP Builder generally available July 1, turning existing integration pipelines and APIs into governed MCP tools. (aiagentsdirectory.com, blog.mean.ceo)

### Coding agents: convergence at the top
By July 2026 seven serious coding-agent contenders exist — Claude Code, Google Antigravity, OpenAI Codex, Cursor, Kiro, GitHub Copilot, and Windsurf (now rebranded Devin Desktop). Recent shifts include Cursor Composer 2.5, Claude Code limit increases following a SpaceX compute deal, GPT-5.6 powering Codex, and Devin 2.0 dropping its entry price to $20. Notably, 65% of working engineers now run two coding agents daily rather than one. (lushbinary.com, aibuilderclub.com)

### Agent research benchmarks mature
New arXiv work this cycle focuses on evaluating agents across the research lifecycle, including suites benchmarking frontier LLMs and agentic harnesses as "real researchers" and MLReplicate, which tests autonomous systems on ML reproducibility. Evaluation frameworks are emerging as the gating factor for trusting agents with longer-horizon work. (arxiv.org)
